# Python 学习题生成 Skill

本目录配合 `$reinforce-python-pdf` skill 使用。将学习笔记和按阶段整理的 PDF 放在这里，即可持续生成可追踪、可复盘的 Python 巩固题。

## 环境要求

需要 Codex 已安装并能发现 `$reinforce-python-pdf` skill。出题和目录初始化还依赖以下命令：

| 工具 | 用途 | Linux 常见命令 | Windows 常见命令 |
| --- | --- | --- | --- |
| Python 3.8+ | 创建练习目录、验证代码 | `python3 --version` | `py -3 --version` 或 `python --version` |
| ripgrep（`rg`） | 快速查找笔记、PDF 和历史练习 | `rg --version` | `rg --version` |
| Poppler 的 `pdftotext` | 从 PDF 提取文字以核对知识点 | `pdftotext -v` | `pdftotext -v` |

在 Linux 中通常通过发行版包管理器安装 `ripgrep` 与 `poppler-utils`；在 Windows 中安装 ripgrep 和 Poppler 后，确保其命令所在目录已加入 `PATH`。初始化脚本仅使用 Python 标准库，因此脚本本身可在 Windows 和 Linux 运行；差异主要来自 `python3`、`rg` 和 `pdftotext` 命令是否可用。

## 资料组织

```text
.
├── readme.md                   # 本说明文件，不作为学习笔记
├── 01_python编程基础/           # 数字前缀表示学习模块/深度
│   ├── 01 AI驱动Python编程.md    # 本模块的学习笔记，出题的第一依据
│   ├── python入门.pdf
│   └── 序列.pdf
├── 02_.../                     # 后续更深入的模块（可选）
└── practice/                   # 自动生成，不要放学习笔记
```

- 每个 `01_...`、`02_...` 模块目录内的 Markdown 笔记优先级最高。更新模块内笔记后，下一次出题会使用新内容；根目录的 `readme.md` 不会作为学习材料。
- PDF 与笔记放在同一模块目录。PDF 用于核对笔记、补足该模块笔记未覆盖的内容，以及参考其中已有题目。
- `01_...`、`02_...` 等目录是不同学习模块。默认使用编号最小的模块；指定模块时不会自动混入更高编号模块。

## 如何使用

直接向 Codex 提出出题请求即可。skill 会自动在当前目录创建：

```text
practice/YYYYMMDD_HHMM/
├── 题目.md
├── 答案与大纲.md
└── feedback.md
```

例如：`practice/20260713_1349/`。同一分钟目录已存在时会停止，避免覆盖旧练习。

完成后，在该次练习的 `feedback.md` 中每道题对应的单个反馈区自由填写答案、思路、卡点或希望继续巩固的内容。下次生成前，skill 总会阅读所有历史的答案与大纲、反馈和题目，避免重复并针对薄弱点重新设计题目。

## 标准提示词

```text
请出题。
```

```text
请基于 01_python编程基础 出一套题，重点复习函数和字符串。
```

```text
请出题，全部都是列表的。
```

```text
请根据 practice 中的 feedback.md 出一套针对错误知识点的巩固题。
```

```text
请出题，难度稍高一些，但只考开发中高频的知识点。
```

可以在请求中指定知识点、模块、难度、题量或题型；这些要求优先于默认范围。比如“全部都是列表的”会让每一道题（包括编程题）都聚焦列表。

## 出题方式

1. 先确定学习模块，再读该模块内的 Markdown 笔记，确定当前学习重点。
2. 再读 `practice/` 中已有的 `答案与大纲.md`、`feedback.md` 和 `题目.md`，避免重复，并针对错题、跳过题和不确定知识点巩固。
3. 需要核对、笔记未覆盖或参考原题时，才读取对应模块中的 PDF。
4. 优先选择开发中高频的知识：数据处理、控制流、函数、字符串和常用集合操作、对象使用、读代码与调试常见错误。
5. 适当加入无歧义的易错点题目，例如边界、赋值与比较、可变对象修改与重新绑定、真值判断。偏门内容只有在理解高频知识所必需时才会出现，并标记为“必要理解点”。
6. 只有确有助于理解或纠正误区时才扩展 PDF/笔记之外的内容，并明确标注扩展原因。

默认每套题为 3–5 道非编程题和 1 道简单编程题。非编程题至少包含 1 道选择题、1 道填空题、1 道判断题；编程题只聚焦知识点本身，不要求完成实际应用。

## 输出文件说明

| 文件 | 内容 |
| --- | --- |
| `题目.md` | 题目、题型、难度与来源；不含答案。 |
| `答案与大纲.md` | 本次范围、题目速览、逐题答案/知识点/易错点/来源/选题原因，以及覆盖和去重说明。 |
| `feedback.md` | 所有题目的单个自由反馈区，每题一个，不再拆分多个字段。 |

来源会标注为笔记标题、PDF 相对路径与页码，或“扩展（原因）”。
